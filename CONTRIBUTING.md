# Contributing

Issues and pull requests are welcome when they improve contract safety,
compatibility analysis, deployment reproducibility, or documentation.

Before opening a pull request:

1. Do not include confidential, personal, customer, or employer information.
2. Add or update tests for behavior changes.
3. Run `python -m unittest discover -s tests -v`.
4. Run the compatibility checker for every changed schema.
5. Explain whether the change is backward compatible.

By contributing, you agree that your contribution is licensed under Apache 2.0.
